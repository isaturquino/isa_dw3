# Exercício 1

O ORM entra depois do SQL porque é importante primeiro entender como o banco de dados funciona e como as consultas SQL são realizadas. O ORM facilita a comunicação entre a aplicação e o banco, mas não substitui o conhecimento de SQL.

Aprender primeiro SQL permite entender melhor o que o ORM está fazendo por trás do código e também ajuda a escrever consultas mais eficientes e identificar possíveis problemas. Por isso, o ORM deve ser visto como uma ferramenta para facilitar o desenvolvimento, e não como uma substituição do SQL.
